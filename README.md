# Image-based 3D object detection using MonoDGP

This repository hosts the implementation of our (Kasper Langhoff, Alexander Engell-Hansen & Otto Esmann Jensen) project in the Computer Vision course at Aarhus University.

The code makes improvements to the existing work [MonoDGP: Monocular 3D Object Detection with Decoupled-Query and Geometry-Error Priors](https://arxiv.org/abs/2410.19590). The original repo can be found at https://github.com/PuFanqi23/MonoDGP.

Our four improvements are in the branches _improve_3d_head_, _auxiliary_height_loss_, _projection-alignment_, and _height-residual-estimation_.
Changes are specified in the changes.md file of each individual branch.
